# 用 AI 完成一次数据竞赛：问题拆解、验证与交付复盘

围绕 **2026 中国高校计算机大赛——大数据挑战赛**，我独立参赛，借助 AI Agent 探索沪深300成分股收益预测与选股。这份作品集整理我的任务判断、方案比较、结果核查和交付复盘，供 AI 应用、业务分析、数字化实施及项目助理方向的招聘沟通使用。

## 最关键的一次纠错

旧训练标签把当天开盘价作为买入价，后续改为次日开盘价。

```text
旧口径：  (第T+5日开盘价 - 第T日开盘价)   / 第T日开盘价
修正口径：(第T+5日开盘价 - 第T+1日开盘价) / 第T+1日开盘价
```

**目标定义变了，旧回测结论就需要重新验证。** 继续增加复杂特征之前，应先确保训练目标和任务要求一致。
