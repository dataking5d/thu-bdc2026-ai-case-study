## 本地检查发现的差异

1. 原 README 描述 LambdaRank 和 NSGA-II；精选提交目录代码为回归和 confidence 权重，展示文档没有沿用旧 README 的现状描述。
2. 本地记忆文件同时保留 v3.1、7月 v4.0 和后续实验信息，因此不拼接各版本的最好指标。
3. 8月元数据标115维，本地提交包模型文本头和特征列 JSON 则为103维。这里只能确认不同快照不一致，没有加载 scaler 或重跑完整推理。
4. 7月冻结摘要与指标 JSON 的部分数值不同。公开说明引用具体 JSON 字段，不能把摘要当作统一的最终成绩。

源码和原始工作记录留在本地，上述代码层面的检查不能由本公开包独立复现。文件来源与摘要哈希见 [清单](../evidence/source_manifest.json)。

## 不能从这些文件推出什么

- 元数据中的 `git_commit` 只是当时保存的版本标识，不是本作品集仓库的提交。
- JSON 可以读取，不代表完整实验可重现；本地分数不是官方榜单或真实投资收益。

- 本人分工、独立参赛、线上有效提交及 B 阶段未提交属于本人确认的经历，当前文件包无法独立证明。
- 官方规则原文、排名阶段、回执、数据许可、完整数据泄漏审计和干净环境容器复现尚未在本轮完整核验。
