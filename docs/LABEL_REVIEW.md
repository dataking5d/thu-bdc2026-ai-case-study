# 一次目标口径纠错

## 为什么这个差异重要

当模型预测日为 T 时，旧标签使用 T 当天开盘作为买入价；修正版使用 T+1 开盘。两者相差的价格区间会改变训练目标。

人工示例：T 开盘100，T+1开盘110，T+5开盘121。旧口径为21%，修正版为10%。这组数字仅用于解释时点差异，不来自比赛数据。

本轮在本地直接调用历史标签函数，人工样例得到上述结果，同时检查了组合函数的 Top-5、权重合计、等权回退和全负分返回空组合。源码没有进入本公开仓库，因此公开文件无法独立重跑该函数检查。

## 能迁移到业务工作的判断

先核对目标定义，再解释效果指标。如果目标与验收标准不一致，更高的分数可能没有回答实际问题。对应的工作步骤是：固定任务口径、记录版本、重新比较方案，并在汇报中交代哪些结论已失效。

修正版与赛事评分规则的对应关系来自历史记录，本轮没有重新核对官方规则页面。标签小样例通过也不等于全量行情中的标签处理没有其他问题。
